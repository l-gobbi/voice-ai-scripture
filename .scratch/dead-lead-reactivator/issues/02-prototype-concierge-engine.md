# 02: Prototype the Concierge Reactivation Engine

Type: prototype
Status: open
Blocked by: None

## Question

What is the cleanest local interactive prototype / CLI tool that allows us to input lead context (Name, Company, Past notes) + Agency info (Niche, Recent win), and generates polished, high-converting reactivation emails (<90 words) and LinkedIn drafts?

Specifically explore:
1. Prompt engineering constraints that eliminate corporate fluff and AI jargon.
2. The 3 core reactivation angles (`case_study_drop`, `quick_question`, `zero_risk_pilot`) and how their outputs compare on realistic test fixtures.
3. A simple, rapid execution method (single Node.js script or browser HTML tool) so we can process audit batches in under 5 minutes.
