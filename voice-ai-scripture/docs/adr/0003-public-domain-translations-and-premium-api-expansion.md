# 0003: Public Domain Built-In Translations with Premium API Expansion

We decided to ship the app initially with public domain translations (King James Version and World English Bible) pre-bundled offline, allowing users to paste copyrighted modern texts manually. Commercial copyrighted translations (via official providers like API.Bible) will be introduced in a future update as a premium feature.

Bundling modern copyrighted translations (such as NIV or ESV) directly requires publisher royalty licensing and complex legal agreements. Public domain texts eliminate legal risk, maintain $0 operational licensing costs, and operate completely offline. Integrating API.Bible later behind the premium subscription ensures API and licensing costs are directly covered by paying subscribers.
